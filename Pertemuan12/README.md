# Login Form with Tailwind CSS

This is a simple login form built using HTML and Tailwind CSS.

## Usage

1. Open `login.html` in your web browser.
2. Fill in the email and password fields.
3. Click the "Sign In" button to submit the form.

## Features

- Responsive design
- Email and password input fields
- Submit button
- "Forgot Password?" link

## Dependencies

- Tailwind CSS (loaded via CDN)

## Troubleshooting

- Ensure you have an internet connection to load Tailwind CSS from the CDN.
- If the styling doesn't appear, check your browser's console for any errors.
